# Trilhas-alvo — RBFFS SMS (`audio/music/`)

> Sem binários: ROM SMS usa PSG (SN76489 via PSGlib). Composições futuras
> com `make_psg_assets.py` + skills sms-psg-*. Arbitragem música×SFX no TDD.

## Temas necessários (quando os stages fecharem)

1. USA Beach (Terry/Mary/Duck) 2. USA Studio (Billy) 3. Germany dia/noite
   (Laurence/Krauser) 4. Geese Tower 5. Demais stages (a levantar)
6. Select / Versus / Continue / Ending (Terry primeiro).
## SFX

Hit, block, KO, Burn Knuckle, Power Wave/Geyser (Terry), wall break
(corner objects destrutíveis), select cursor, round call.
## Restrições SMS

3 tone + 1 noise; funcionar sem YM2413; tabelas em ROM, sem float, pools
estáticos. Guia auditivo: gravações Neo-Geo fora do repo; partitura autoral.
